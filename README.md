# Python Journey

A structured, public log of my Python learning: weekly exercises, short notes, and small projects.

## About

I am following a 60-day structured Python plan, studying every day, with the long-term goal of working in AI and quantitative problem-solving. This repository records the process honestly, including early and imperfect code, so progress is visible over time.

## Repository structure

| Folder | Purpose |
|--------|---------|
| `week-01/` ... `week-09/` | Practice scripts and exercises for each week |
| `notes/` | Short written summaries of concepts I have learned |
| `projects/` | Larger projects built from what I have learned |
